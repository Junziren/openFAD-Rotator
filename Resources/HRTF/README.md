# HRTF asset slot

The current Binaural mode ships with a lightweight parameterised HRTF-style approximation (short interaural delay, frequency-dependent head shadow and crossfeed). The Studio binaural pass reserves this directory for one redistributable SADIE II KEMAR SOFA asset.

Do not add a proprietary or unreviewed HRTF file here. Before shipping, copy the selected SOFA file, its upstream attribution, the applicable Apache-2.0 notice, and a small manifest containing the source URL, capture profile, sample rate and preprocessing hash.
